# Laravel-ChatApp-SnapTalk-
💬 Real-time chat application built with Laravel, Vite, Vue.js, and MySQL — enabling private messaging, live updates, and modern UI experience.
## 🚀 Features

- 🧑‍🤝‍🧑 User registration and authentication  
- 💬 Real-time one-to-one messaging  
- 🔔 Instant message notifications  
- 🕒 Message timestamps and delivery status  
- 📱 Responsive chat interface (mobile & desktop)  
- 🧩 Built with Laravel + Vite + Vue.js  
- 🔐 Secured with Laravel’s authentication system  

---

## 🧠 Tech Stack

| Category | Technology |
|-----------|-------------|
| Backend | Laravel 11 (PHP 8+) |
| Frontend | Vue.js (with Vite) |
| Database | MySQL |
| Styling | Tailwind CSS |
| Real-time | Laravel Echo + Pusher (or WebSockets) |
| Authentication | Laravel Breeze / Sanctum |
